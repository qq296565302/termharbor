# UI 重构计划（0.2.x）

> 目标：把「能用」提升到「像一个卖钱的产品」。约束是不改任何交互逻辑与 IPC，
> 只动样式层与少量 DOM 结构（加图标、分组、容器）。

## 一、现状诊断

用 Edge headless 实拍连接/终端/设置/关于四页，问题归为六类：

1. **层次消失**：`--bg`(#f5f8fb)、`--bg-muted`(#e9eff6)、`--bg-sunken`(#edf2f8)
   三色差 3~5%，而 `.card` 与 `.content` 都用这组变量 —— 卡片和页面同色，
   只能靠 1px 边框分辨，于是整页糊成一片。
2. **色调发脏**：`--border: rgba(13,148,136,.16)` 把青绿混进所有分隔线，
   大面积看偏灰绿；`--danger` 用洋红 #d81b60，与青绿撞色。
3. **没有尺度体系**：按钮 padding 出现 `5px 12px` / `3px 9px` / `4px 14px` 三种，
   字号出现 10.5/11/11.5/12/12.5/13/14 七种，圆角 4/5/6/7/8 五种。
4. **控件原始**：字体滑块是原生 `<input type=range>`；列表里的操作是裸文字按钮；
   终端工具栏四个按钮（+新连接/片段/文件/负载）等权排列，看不出主次与分组。
5. **布局不明**：设置页是一条长滚动，没有分区导航；连接页左右比例失衡
   （左 240px / 右侧一整块空卡片）；顶栏除标题外全空。
6. **开发语汇外露**：状态栏显示 `INTERNAL`，顶栏版本号显示 `–`。

## 二、设计原则

- **工具感，不是落地页感**：中性灰阶 + 纯白面板 + 单点品牌色。不要渐变、玻璃、大字留白。
- **层次靠三件套**：底色差 + 中性边框 + 极轻阴影。不靠粗细和颜色喊话。
- **一色一用**：青绿只给主操作与选中态；语义色只给状态。其余全部灰阶。
- **密度优先**：基准字号 13px，控件高 28px，行高 1.5 —— 长时间盯着看不累。
- **图标一律 1.5px 线性 SVG**，16px，不用 emoji、不用彩色图标。

| `--bg-subtle` | `#F9FAFB` | 表头、hover、次级填充 |
| `--bg-sunken` | `#F2F4F7` | 凹陷区（代码块、终端外壳） |
| `--border` | `#E7E9EE` | 常规分隔 |
| `--border-strong` | `#D5D9E0` | 控件描边 |
| `--text` | `#171A20` | 主要文字 |
| `--text-muted` | `#5A6472` | 次要文字 |
| `--text-faint` | `#8D96A5` | 弱提示 |
| `--accent` | `#0D9488` | 品牌青绿（保留） |
| `--accent-hover` | `#0B7F75` | |

| `--ok` / `--warn` / `--danger` | `#12805C` / `#B54708` / `#C4321B` | 语义 |

阴影：`--shadow-xs` 1px/2px、`--shadow-sm` 1px/3px、`--shadow-md` 6px/16px、`--shadow-lg` 16px/40px，全部用 `rgba(16,24,40,·)` 中性黑。

### 暗色

底 `#0F1115`、面板 `#16191F`、次级 `#1C2027`、凹陷 `#0B0D11`、
边框 `#262B33` / `#343A45`、文字 `#E8EBF0` / `#9AA4B2` / `#6B7480`、
主色提亮到 `#2DD4BF`（暗底上 #0D9488 对比度不够）。

## 四、组件规格

- **按钮**：高 28，padding `0 11px`，gap 6，`--r-md`，边框 1px，`--shadow-xs`。
  变体 `--primary`（实心青绿）/ `--ghost`（无边框，hover 显底）/ `--danger` /
  `--icon`（28×28 正方形）/ `--small`（高 24）。`focus-visible` 统一 3px ring。
- **输入**：高 28，与按钮同半径同描边，focus 时边框转主色 + 3px 柔光环。
- **卡片**：白底 + `--border` + `--r-lg` + `--shadow-xs`，padding `16px 18px`。
- **工具组**：同类操作装进 `.toolgroup`（1px 分隔线分组），主操作单独靠左/右。
- **导航**：16px 线性图标 + 文字，选中态「2px 主色竖条 + `--bg-subtle` 底 + 500 字重」。
- **状态栏**：28px，11.5px 字，去掉 `INTERNAL` 这类内部枚举，改人话。

### 第 8 步做了什么（四个面板）

- **文件面板**：去掉三块各自带边框的圆角盒子，改成「工具栏 / 路径条 / 列表 / 传输区」
  四段贴边结构。工具栏导航三件套（上一级 / 刷新 / 回家）收成一组图标，上传升为主色按钮。
  emoji 图标（📁 📄 🔗）换成 16px 线性描边。行内「下载 / 重命名 / 删除」三个中文词
  要吃掉 130px，改成图标按钮后名称列从 68px 回到 180px。
- **诊断浮层**：结论条独立成块（左侧主色竖条 + 浅底），原文里它和正文同字号同色，
  混在几十行表格上方等于没写。表头改浅底小字、sticky 边框改为 separate 模式。
- **负载看板**：卡片从 `bg-sunken` 改成纯白 + 边框 + 阴影，看板底色下沉一档 ——
  原来每块卡片都比底色更脏，一排看下来像表格截图。分核标签移到进度条**前面**，
  否则「条 | c0」会把这条的归属读成下一核。
- **片段侧栏**：条目改白卡片浮在 sunken 底上；只读片段不再挂「只读」标签（一列全同
  等于没标签），会改动系统的挂「改动 / 高危」文字标签 + 左侧 2px 竖条（只靠颜色区分
  对色弱和暗色主题都不可靠）；行内操作改图标并竖排，20px 高是为了两个按钮加起来
  正好落在 46px 的卡片内。

**顺手修掉的两个真缺陷：**

- **表头与正文整体错位 58px**：`.files-row` 每行是**各自独立的 grid**（不是 table），
  最后一列写 `auto` 时，表头那行是空 span 算出 0、数据行有三个图标算出 58，
  于是从第二列起逐列右移。改成固定列宽后一致（用 CDP 量 rect 验证：
  表头 198/280/408/474，数据行 198/280/408/474）。
- **紧凑模式把按钮压歪**：`.files-bar .btn { padding: 3px 7px }` 在定高 flex 按钮上
  等于上下各加 3px，同行图标就高出按钮一截。改成只压 height 和左右 padding。

### 已发现的实现缺陷（顺手修掉）

- **`.btn--sm` 与 `.btn--small` 拼写不一致**：21 处写了 `btn--sm`，CSS 里只有
  `.btn--small` —— 那些小按钮一直按默认尺寸渲染，工具栏因此显得笨重。两个名字现在都认。
- **滑块是原生控件**：`accent-color` 只改颜色，轨道仍由浏览器绘制。改为自绘轨道 +
  已选段渐变（`--pct` 由 JSX 计算）。

**风险控制**：每步结束都跑 `tsc --noEmit` + 截图比对；样式只增不删，
旧选择器保留到该页改完再清理，避免一次性大改导致某页崩掉找不到原因。

**验证方式**：`npx vite` + Edge headless CDP 截图（脚本在 `.workbuddy/ui-shots/`），
每步存 before/after 对照图；暗色用 CDP 模拟 `prefers-color-scheme: dark` 单独取证。

## 六、怎么取证

本机执行环境建不起 WebView2，`vite dev` 打开普通浏览器时 `isDesktopRuntime()`
为 false，所有 IPC 直接抛错 —— 面板只会显示空态，改完样式看不到效果。

为此有一个**只用于取证**的预览页：`ui-preview.html` + `src/dev/UiPreview.tsx`。
它往 `window.__TAURI_INTERNALS__` 里塞一个按命令名返回假数据的 `invoke`，
把文件面板 / 片段 / 负载 / 诊断四个组件挂出来：

```bash
npx vite --port 1420                          # 起开发服务器
node .workbuddy/ui-shots/shot-panels.mjs 标签  # 截四张（含暗色）
```

`?panel=diag` 单独渲染诊断浮层。它不在 `vite build` 的入口里，不会进安装包。

**量尺寸比看截图可靠**：`node .workbuddy/ui-shots/measure.mjs` 用 CDP 直接读
`getBoundingClientRect`，表头错位那次就是靠它确认「每行独立 grid 导致 auto 列宽各算各的」。
截图里的"溢出"有一半是误判 —— 白卡片贴在近白底色上，边界根本看不出来。
